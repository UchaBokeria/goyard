# GoYard Documentation

## Overview

GoYard is a comprehensive web framework toolkit for Go, providing essential components for web development.

## Components

- **Controller**: HTTP request handling with enhanced context management
- **Templ**: HTML templating with component-based approach
- **HTMX**: Integration with HTMX for dynamic UI updates
- **Alpine.js**: JavaScript framework integration
- **Tailwind CSS**: Utility-first CSS framework support
- **Hot Reloading**: Development tools for fast iteration
